# 长会话与跨会话候选意图识别评测协议

更新：2026-11-04。当前两层实现与小规模诊断测试见 [验证记录](../MINDTRACE_V2_REPORT.md)；下述独立人工复核等完整方案仍是目标协议。原协议状态：**方案与人工合成示例，尚未完成新数据集及完整会话对照运行**。本协议不修改历史实验结果，也不宣称下述能力均已实现。

## 1. 评测目标

检验 Agent 能否从分散经历中识别有证据支持的候选跟进意图，并在用户状态变化后更新判断。参考 [CogniFold/CogEval-Bench](https://arxiv.org/html/2605.13438) 的可控事件和概念构造思路；本协议是心理支持场景下的自建扩展，不是官方 CogEval-Bench。

“候选意图”是值得向用户确认的跟进方向。它不等于用户已明确同意的目标，也不等于心理诊断。显式表达的目标和需要多事件综合的候选意图分别统计。

## 2. 示例：学习疲劳与家长增加辅导课

下表日期、人物和发言全部是人工合成；时间统一为 Asia/Shanghai（UTC+08:00）。表中列出的是关键发言，最终样本还需展开成完整双方对话，不能把这四句话冒充已生成的长会话。

| 消息 ID | 发言时间（跨会话示意） | 用户事件 | 概念 |
| --- | --- | --- | --- |
| s1_u4 | 2026-10-12T20:10:00+08:00 | 这周三次都到一点多才写完作业，早读时很困。 | 学习安排挤占休息、持续疲劳 |
| s1_u16 | 2026-10-12T20:38:00+08:00 | 每天放学后先上补习班，回家已经九点多。 | 学习安排挤占休息 |
| s2_u8 | 2026-10-16T20:20:00+08:00 | 周末原本留了半天休息，后来又被加了一节课。 | 休息空间继续减少 |
| s3_u6 | 2026-10-20T20:15:00+08:00 | 妈妈觉得最近成绩没起色，还准备再报一门。 | 家长继续增加学习投入 |

事件 → 概念：多个经历共同呈现学习安排造成的休息挤占；新增事件又揭示家长继续增加安排。

概念 → 候选意图：**讨论如何向家长表达学习负担，并协商学习与休息的安排。**

这是可询问的候选方向，不应输出“用户已经决定退课”。“寻找可行的学习与休息调整方式”等合理等价方向可纳入人工可接受答案集合；不能把唯一措辞当成唯一正确答案。若证据不足以判断是否涉及家长沟通，允许输出更宽的候选方向或待澄清状态，由标注规范明确边界。

配对变化分支：在后续会话加入“妈妈已经帮我取消了两门课，这周开始晚上能早点休息”。检查系统是否重新评估或降低原候选方向的优先级，而不是自动认定整个问题完全解决。只有明确表达“不需要继续讨论，问题已解决”的分支，才标为已解决；“暂时不想聊”标为拒绝/暂停。

重复提及同一件事、讲同学的经历、单次疲劳但无持续模式等另设负例或信息不足样本。不得用“事件数量达到三条”直接定义正确答案。

## 3. 数据集构造：先人工设计事件及对应意图，再分散到对话

1. **人工设计人物轨迹。** 定义人物背景、按时间发生的具体事件、可能形成的概念、候选意图与证据关系。可参考许可适用的公开案例，但人工补写部分必须标注为合成；不使用真实学生身份信息。
2. **设计正例和反例分支。** 覆盖学业、家庭沟通、同伴与作息；加入第三方、重复转述、正常活动、解决、拒绝和纠正。区分显式目标与多事件综合，不把“高频主题”直接当作意图。
3. **生成两种对话。** 长会话将相关事件分散到单一 session 的前中后段；跨会话将事件分散到同一用户的多个 session，保留自然开场、上下文、实际状态变化和会话结束。完整样本包括咨询师回复，不能只有事件列表或统一占位回复。
4. **加入自然干扰。** 其他话题、暂时转移和相似但不相关的经历交错出现；干扰不都用极易排除的天气/午餐句子。不在用户发言或咨询师回复中直接植入金标标签。
5. **保存时间。** 每条消息具有 `message_id/session_id/role/sent_at/content`；消息时间不等于事情发生时间，回忆中的“上周”等按文本和已知锚点解释，未知时间保持未知。
6. **独立复核实际对话。** 对照生成结果重新标注候选意图及支持/反向证据；预设意图仅是构造目标，若最终对话不支持，应改标签或弃样。标注者不以系统预测为依据。对核心多事件样本进行单事件可判定性检查；单句就泄露答案的样本转入简单子集。
7. **按原始人物轨迹划分。** 同一轨迹、改写和配对分支全部放在同一开发/验证/测试划分，测试集冻结后不用于调参。数量在实际构造后报告，不预先宣称已完成的规模。

[MusPsy](https://arxiv.org/html/2506.06626v1) 的种子对话扩展和 [TheraMind](https://arxiv.org/html/2510.25758v1) 的逐会话指引可辅助对话展开；这些论文不提供本项目的现成意图分类金标。模拟器的私有人物计划、未来指引与病例结局不得进入被测系统。

## 4. 检查时刻是什么

检查时刻是评测程序读取预测的固定时间点，例如长会话第 10/30/60 个用户回合后，或各次会话结束时。数字是配置示例，不是已构造的数据规模。

每个时刻分别标注截至当时支持的候选意图、状态及消息证据；早期可能应输出空集合，后期才出现意图，更晚又可能因纠正而失效。不能用最终结局反向给早期时刻标答案。

图谱按既有机制持续处理消息，检查时刻不强制创建 Intent。为避免异步写入是否完成造成歧义，主评测在相应批次任务完成或明确超时后取快照并记录状态；不临时额外调用完整历史模型为图谱补答案。后续可单列实时延迟评测。

## 5. 新主对照：带时间的完整会话模型

| 条件 | 图谱方法 | 完整会话直接识别 |
| --- | --- | --- |
| 数据 | 同一用户截至检查时刻的对话流 | 同一范围的全部双方对话 |
| 时间信息 | 持续写入时保留时间与来源 | 输入保留时间戳、顺序、session 边界、角色及消息 ID |
| 预测来源 | 当前图谱已经产生的有效 Intent 节点，保留支持事件/原消息 ID | 同一基础模型直接阅读完整对话后输出候选意图和证据 |
| 不允许 | 评测时额外读取完整历史重新推断后冒充图谱节点 | 用最近窗口或摘要替代全部历史；看到未来消息、金标或图谱预测 |

输入格式示例：

```text
[session=s1 start=2026-10-12T20:00:00+08:00]
[id=s1_u4 time=2026-10-12T20:10:00+08:00 role=user]
这周三次都到一点多才写完作业，早读时很困。
[id=s1_a4 time=2026-10-12T20:10:12+08:00 role=assistant]
（原始咨询师回复；最终数据中保留实际文本）
...
[session=s2 start=2026-10-16T20:00:00+08:00]
...
```

上面的省略号仅用于展示格式，实际基线必须输入完整文本。统一提示：

> 根据截至当前检查时刻的全部对话，识别有证据支持、尚未解决的候选跟进意图。保留用户否认、纠正、已解决和拒绝的信息；不要把话题、情绪或咨询师建议直接当成用户意图。每项输出候选意图、状态、支持证据和反向证据的消息 ID，证据不足返回空列表。只输出 JSON，不要向用户提问或读取外部资料。

统一输出：

```json
{
  "intents": [
    {
      "description": "讨论如何向家长表达学习负担，并协商学习与休息的安排",
      "status": "candidate",
      "evidence_ids": ["s1_u4", "s1_u16", "s2_u8", "s3_u6"],
      "counterevidence_ids": []
    }
  ]
}
```

图谱输出用固定序列化规则转换到相同结构，事件 ID 回溯到原消息 ID；没有有效 Intent 则输出空列表，不让额外模型基于原对话替它重新生成意图。

两种方法使用相同基础模型版本，固定各阶段提示、解码参数和输出约束；模型生成与图谱抽取的角色不同，但预测范围和标签定义一致。超出完整会话模型上下文限制时必须单列为超限，不能静默截断仍称完整会话。对照模型只看到对话，不获得人工设计的概念图或参考答案。

## 6. 如何计分

两边都与**独立人工金标**比较，完整会话模型不是正确答案，也不担任唯一裁判。候选意图按预先冻结的语义标准/类别映射做一对一匹配；多个措辞对应同一目标时不重复加分，不能用只有关键词重合的宽泛主题判正确。开放描述的歧义项由盲化人工复核，不能对图谱方法放宽标准。

- 有无候选意图的二分类准确率、precision、recall、F1。
- 候选意图类别/集合的 precision、recall、F1，区分“有意图但目标错误”和正确识别。
- 证据匹配、用户主体正确性、状态更新，以及解决/拒绝后的错误跟进率。
- 长会话、跨会话、多事件综合和显式目标分别报告；检查点可逐次统计，不确定性按原始人物轨迹聚类计算。
- 输入长度与累计 token/费用、延迟一起报告；图谱方法包括抽取、巩固及更新成本，不只计算读取 Intent 的开销。

若要证明概念层本身的贡献，另加保留相同事件但移除概念聚合的消融。图谱准确率高于最近窗口，不能单独支持“优于完整历史模型”或“概念层必不可少”的结论。

## 7. 会话结束后巩固：待实现、待验证

计划在明确结束或空闲时整理尾批事件、更新概念/候选意图及解决/拒绝状态，并保留原始证据。可在相同跨会话样本上对比开启/关闭巩固；这属于额外消融，不替代完整会话主对照。当前每五轮抽取和已有空闲摘要不等于此完整巩固流程已实现。

## 8. 历史结果与本协议的边界

原 [50 例合成诊断实验](../INTENT_ABLATION_REPORT.md) 对比的是最近六条用户发言，已有 92% 对 50% 的记录。本协议改用带时间的完整会话作为主对照，数据构造与标注也需另行完成；**尚无本协议下的准确率或提升结果**，不得把历史数字直接移植到新方法说明中。
